
# Simple Interest Calculator

## Project Description
This project is a simple interest calculator developed using Bash scripting. It takes the principal amount, annual rate of interest, and time period as input and calculates the simple interest.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Input Parameters
- Principal: The initial amount of money.
- Rate: The annual rate of interest in percentage.
- Time: The duration in years.

## Technologies Used
- Bash
- Git
- GitHub

## How to Run
1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Run the script using:
   `bash simple-interest.sh`
4. Enter the principal, rate of interest, and time period when prompted.

## Expected Output
The program calculates and displays the simple interest based on the supplied values.
